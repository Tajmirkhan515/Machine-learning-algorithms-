# Machine Learning & Deep Learning Experiments

  

## Overview
This repository contains practical implementations of machine learning and deep learning techniques for learning and experimentation purposes. It includes projects ranging from linear models to convolutional neural networks (CNNs), dataset handling, and model training using TensorFlow and Keras.

## Repository Structure
- **classification.ipynb** – Step-by-step classification tasks with preprocessing, scaling, and predictions.  
- **Train Neural Network by loading your images TensorFlow, CNN, Keras.ipynb** – Training CNNs on image datasets with TensorFlow and Keras.  
- **training neural network cnn/** – Folder containing code and resources for training CNNs.  
- **Linear Regression vs Regularization Ridge (L2).ipynb** – Comparison of linear regression with L2 regularization.  
- **from scratch, how clean, scaling, etc, and predict.ipynb** – Data cleaning, scaling, and prediction implemented from scratch.  
- **linear model using_data of _gdp_per_capita.ipynb** – Linear regression model applied on GDP per capita data.  
- **.gitattributes** – Git configuration file.  

## Key Features
- Implementations of CNNs for image classification.  
- Step-by-step data preprocessing: cleaning, scaling, and transformation.  
- Examples of linear models and regularization techniques.  
- Hands-on experiments to understand TensorFlow and Keras workflows.
